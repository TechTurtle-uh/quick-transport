# 🚗 Quick Transport

Quick Transport is a web-based transportation and ride booking management system designed to provide users with a simple interface for booking rides, managing ride history, payments, and user accounts.

## 📌 Features

- 🔐 User Registration & Login
- 🚕 Ride Booking
- 📍 Pickup and Destination Selection
- 🗺️ Map Integration
- 📋 Ride History
- ❌ Ride Cancellation
- 💳 Payment & Wallet Management
- 💰 Add Money to Wallet
- 🆘 Help & Support Section
- 📱 Responsive Web Interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- XAMPP
- Git & GitHub
